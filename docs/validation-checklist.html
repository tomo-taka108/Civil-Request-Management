手動テスト用チェックシート

入力項目バリデーション一覧

ブラウザで各画面を開き、下の「試す操作」を実際に入力して、表示されるエラーメッセージが「期待されるメッセージ」と一致するか照合してください。確認できたら右端の ☑ を入れると進捗が残せます（このページ内でのみ保持）。

確認の進め方

  1. 一般職員でログイン（登録・編集は一般職員のみ。管理者は登録不可）
  2. 案件登録 /requests/create、案件編集 /requests/{id}/edit を開く
  3. 各行の「試す操作」どおりに入力して「登録／更新」ボタンを押す
  4. 表示されたエラー文と「期待されるメッセージ」を見比べる
● 必須 ● 任意 ● 条件付き（他項目に依存）

ユーザー

ユーザー 登録・編集フォーム

/admin/users/create ・ /admin/users/{id}/edit ／ システム管理者でログインして確認。権限区分によって所属事務所・担当部署の要否が切り替わる。

担当部署

権限区分を「システム管理者」にすると、所属事務所・担当部署は画面で隠れ、送信されても自動で無視されます（管理者は事務所・部署を持たない仕様）。
